## 备份与恢复

1. 在主页打开 **设置 → 导出全量备份**。
2. 等待 JSON 下载完成。备份包含 API Key 和 Token，请放在私人目录。
3. 需要恢复时选择 **导入全量备份**。验证成功并落盘后页面自动重新打开。
4. 误导入可使用 **恢复到上次导入之前**。只保留一个恢复点，每次导入会更新它。

图片打包采用有限并发与超时。无法下载的图片保留原地址，导出提示和 JSON 的 `externalImages` 会说明未内嵌的数量。外链仍需要网络，不能把含外链的备份视为完全离线素材包。Prompt 正文内的任意图片链接不自动改写。

兼容旧版 3.x All-in-One 和 `nextTiers` 包装格式；不宣称支持任意 AI Studio 项目 ZIP 或其他结构的 JSON。导入旧备份时，文件没有的小剧场字段保持当前值。

## 保存位置

- 浏览器：IndexedDB 数据库 `bgm-anitier-user-data-v1`。迁移时保留旧 localStorage 内容作为恢复来源；后续编辑以 IndexedDB 为准。
- 本地 Express：`.data/user-state.json`，上一代为同名 `.bak`。设置面板应显示“已保存到浏览器和本机文件”。
- Cloudflare Pages：用户存档只保存到当前浏览器，没有服务器存档或跨设备同步。换设备或清浏览器前必须先导出。
- 关闭页面前等待保存完成。不同浏览器、端口或设备有不同的浏览器存储。
- 不建议同时在多个页面修改同一项。冲突时先导出当前页面，刷新后决定采用哪个版本。浏览器和服务器均有未同步修改时，可导出当前版本后明确选择备份导入。
- 服务器存档请求默认上限 200 MB，可通过 `STORAGE_BODY_LIMIT` 调整。保存错误不会删除已有存档。
